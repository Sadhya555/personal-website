ESP32 Pulse Oximeter & Heart Rate Monitor

working build

An electronics project that measures SpO2 (blood oxygen) and heart rate using an ESP32, a MAX30102 optical sensor, and a small OLED display. It uses digital signal processing to separate the AC and DC components of the sensor's optical signal, which is what makes the SpO2 and heart-rate readings meaningfully accurate rather than just raw sensor noise. This is a hobby electronics build, not a medically rated device.

Hardware
ESP32 dev board, MAX30102 pulse oximetry sensor, 0.96″ SSD1306 OLED (I2C), 2× 4.7kΩ pull-up resistors
Software
PlatformIO / Arduino framework, Adafruit GFX & SSD1306 libraries, SparkFun MAX3010x sensor library
Status
Hardware built and wired; a browser-based dashboard mirroring the OLED display is planned as a future addition
